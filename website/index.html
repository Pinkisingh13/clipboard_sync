Local Wi‑Fi · Text clipboard

Clipboard Sync

Copy on the Mac, paste on Android — and the other way. You need both apps. Nothing is uploaded to the cloud.

  • Mac app and Android app — one side is not enough
  • Same Wi‑Fi on both devices
  • Plain text only (no images or files yet)
  • Keep the Mac app open while you sync

Download

Install both, then start the Mac server and connect the phone.

Mac

Desktop server. Double‑click the app inside the disk image.

Download .dmg Download .app (zip)

Unsigned build. If macOS blocks it: right‑click the app → Open → Open.

Android

Phone client. Install, then tap your Mac in the list.

Download Android app

Android will ask to allow installs from the browser. That is normal for a direct download (not Play Store).

How to use

  1. Install the Mac app and the Android app.
  2. On the Mac, start the server.
  3. On the phone, wait until your Mac appears, then tap it.
  4. Copy text on either device. It shows up on the other clipboard.
